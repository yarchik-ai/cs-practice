Git - это система контроля версий, Git позволяет сохранить историю изменений моего проекта. Github - это облачная платформа для хранения Git-репозиториев и совместной работы.
git diff показывает изменения, которые находятся в рабочей директории, но ещё не добавлены в индекс. git diff --staged показывает изменения, уже добавленные в индекс и подготовленные для следующего коммита. Обе команды сравнивают изменения с последним коммитом, но первая рассматривает рабочую директорию, а вторая — область подготовленных изменений (staging area).

Раздел Использованные команды:
git status - узнать состояние проекта
git diff - показывает изменения, которые находятся в рабочей директории, но ещё не добавлены в индекс
git diff --staged - показывает изменения, уже добавленные в индекс и подготовленные для следующего коммита

Раздел Ветки:
Ветка — это указатель на commit, от которого Git продолжает историю.При commit сама ветка не создаётся и не копируется. Она просто перемещается на новый commit. git merge - слияние, которое объединяет историю отдельной ветки с главной.
